## 3. ปัญหาที่เจอระหว่างทำ (สำหรับ #15)
- `communities.csv` ที่มี BOM ทำให้ GEE ตั้งชื่อ property เป็น `\uFEFFcommunity_id` ผลคือ `community_id` ว่างทั้งไฟล์ แก้โดยสคริปต์ GEE รองรับ BOM และไฟล์ master ใหม่เป็น UTF-8 ไม่มี BOM
- ส่วนอาคารใน GEE พังหลายรอบ (อ่าน property ผิดชื่อ, กรองด้วยจุดแทนพื้นที่รอบ, ซ้อน filter ในลูป) แก้เป็นการคำนวณผ่านราสเตอร์
